## Cara pakai

1. Nemu jadwal baru di X / Discord → buka `index.html`, tekan <kbd>N</kbd>, tempel teks pengumumannya ke kotak paling atas picker. Tanggal & jamnya kebaca sendiri.
2. Pilih **tipe** (WL / presale / mint / airdrop / …) dan **status** awal (biasanya `Pantau` atau `Sudah daftar`).
3. Begitu dapat WL, ganti statusnya langsung dari tabel — tidak perlu buka dialog.
4. Untuk WL yang lolos, klik **Duplikat** supaya baris MINT-nya ikut terjadwal.
5. Setelah waktunya lewat, barisnya pindah sendiri ke **Sudah Lewat**. Isi **Hasil / catatan akhir** lewat **Edit**.
6. Kalau mau ditulis manual di file ini, salin dari **Salin Markdown** di footer app.
